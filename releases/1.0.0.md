# Arches QGIS Plugin 1.0.0 release notes

- Authenticates via built in qgis authentication and django oauth toolkit.  


## Notes

### Getting Authentication Working
1. In Arches, register a new application at /o/applications.  Set the client type to "public", grant type "Authorization code".  Hash the client secret and make sure you save both the client secret and the client id - they will not be available again. Set your redirect url to http://127.0.0.1:7070/ - this is important because if it's not set properly, arches will not direct you back to qgis.  Save this client.
2. In QGIS, go to the QGIS-LTR menu.  The click Preferences -> Authentication.  A space will open for you to add a configuration.  Click the green plus on the right.  
    - Give this configuration a name - this is what the QGIS User will see when logging in, so give it a sensible name like "Arches" or somesuch.  
    - In resource, add your base arches URL, something like https://arches.example.com/en/ - only include the i18n suffix (/en in this example) if your arches install includes it.  
    - Choose Oauth2 Authentication.  
    - Grant flow should be set to Authorization Code PKCE.  
    - Add a description if desired.  
    - For request URL set to  https://arches.example.com/o/authorize/
    - For token URL and refresh token URL set https://arches.example.com/o/token/ 
    - Do not change the redirect URL.  
    - Set the ClientID to the one you created in /o/applications.  You will not need the client secret.  
    - Save this configuration and you should be good to use the plugin.
